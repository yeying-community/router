# 模型路由架构

本文描述 Router 当前模型路由主线。历史 V1 / V2 / V3 / V4 文档只保留在 [../历史归档/](../历史归档/) 中，不作为当前入口。

## 主链路

```plantuml
@startuml
start
:接收模型请求;
:校验 API Token;
:加载用户、分组和权益;
:识别端点协议和模型;
:筛选可用渠道;
if (存在可用渠道?) then (是)
  :选择渠道;
  :转发到供应商;
  if (调用成功?) then (是)
    :记录用量;
    :执行扣费;
    :返回响应;
  else (否)
    :按错误类型判断重试和禁用;
  endif
else (否)
  :返回无可用渠道错误;
endif
stop
@enduml
```

## 当前原则

1. Router 不做跨端点协议的隐式转换。
2. 下游请求什么端点协议，Router 就按该端点协议处理。
3. 供应商 adaptor 只处理供应商特有差异，不改变请求的计费语义。
4. 渠道可用性、模型能力、分组暴露和计费规则需要分别建模。
