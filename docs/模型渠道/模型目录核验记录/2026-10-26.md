## 处理原则

- MiniMax 的文本模型可以用现有 token 价格和条件价格组件准确表达，不应因视频等其他模型计费复杂而整体暂缓。
- `MiniMax-M3` 目录默认价仅登记 Standard 服务层。当前运行时价格选择属性不包含 `service_tier`，Priority 价格需在渠道价格中单独配置，避免登记了却无法正确匹配。
- 智谱官方价格接口已给出 GLM-5.3 系列的输入、输出和缓存命中价，因此替换先前的空价目录记录。
- 官方标注的“缓存存储限时免费”不固化为永久零价，防止促销结束后错误计费。

## 兼容性与副作用

- 修正文件是追加的增量目录；加载后按供应商和 canonical model name 合并成完整目录。
- migration 仅刷新 `minimax` 和 `zhipu` 的供应商模型及价格组件。
- 不创建、不启用 `channel_models`，不自动发布分组模型，不覆盖渠道层人工价格。
- migration 可重复执行，模型和价格组件数量保持幂等。
