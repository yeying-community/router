# Router 文档入口

本目录沉淀 Router 当前架构、运行规则、接口契约、部署运维和历史归档。

文档治理原则：

1. 当前实现优先放在主题目录，不用 V1 / V2 / V3 文件名表达主线。
2. 历史方案统一进入 `历史归档/`，不得作为日常入口。
3. API 路径和字段以 [接口契约/router.openapi.yaml](./接口契约/router.openapi.yaml) 为准。
4. 文档中的代码路径使用仓库相对路径，避免写本机绝对路径。

## 提交前核对

1. 涉及 API 变更时，同步更新 [接口契约/router.openapi.yaml](./接口契约/router.openapi.yaml)。
2. 涉及登录边界变化时，同步更新 `身份登录/` 下的方案文档。
3. 涉及路由、端点、供应商、渠道变化时，同步更新 `模型路由/` 和 `模型渠道/`。
4. 涉及计费、套餐、支付变化时，同步更新 `商业计费/`。
5. 涉及历史字段、兼容逻辑或废弃方案时，明确当前是否仍生效。
